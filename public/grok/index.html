Sales Desk

Grok Bot installer for Phuket tour operators. Paste this URL into a new agent:

https://www.folstad.ca/grok/salesdesk.md

In Grok Bot: New → Create new agent → paste the URL → send. The Bot fetches the profile, downloads scrape scripts, then asks for website / Gmail / WhatsApp.
